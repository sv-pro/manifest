# shared/tier-colors.ts

UI color constants for tier visualization in charts and badges.

## Exports

24 named color constants (slate, gray, zinc, stone, red, orange, amber, yellow, lime, green, emerald, teal, cyan, sky, blue, indigo, violet, purple, fuchsia, pink, rose, navy, white, black) plus a `DEFAULT_TIER_COLOR` (indigo).

Used by the frontend to render tier-colored sparklines and the tier badge in the Messages log.
